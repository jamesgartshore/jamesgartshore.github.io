Separate Accounts

By James Gartshore · 02 November 2026 · Scams and staying safe
See the old version of this poster Download the old version

Hi everyone, I wanted to share a simple tip that can make a big difference to keeping your computer safe: using separate accounts for different things.

Most problems on computers happen when we download something we shouldn't, click a bad link, or install a program we don't need. If the account you use every day has full control of the computer, anything harmful you accidentally run has full control too. If your everyday account can't install programs, a harmful download can't do nearly as much damage.

The idea is to have one administrator account, which can install programs, change important settings and install updates. Give it a strong password and only use it when you need to. Then use a standard account for everything else, like browsing the internet, email, watching videos and Facebook. On a Windows computer, you can add a new account and change an account's type in Settings, then Accounts, then Other users.

Make sure User Account Control is switched on too. It's the box that pops up asking for permission before anything gets installed or changed. If you're using a standard account, it will ask for the admin password, which gives you a moment to stop and think. You can find it by searching "User Account Control" in the Windows search bar.

You can also keep your banking and bills separate from everyday browsing by using a separate browser profile. In Chrome or Edge, click your profile picture in the top corner and choose Add profile. Use that profile only for your bank and other important accounts.

The simple rule is: one admin account, a normal account for every day, and always think before you click.

If you'd like help setting this up, just send me a message and I'll walk you through it.
