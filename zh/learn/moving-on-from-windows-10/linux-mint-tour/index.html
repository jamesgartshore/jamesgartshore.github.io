换用 Linux Mint

本课内容

  • Linux Mint 里的东西都在哪儿
  • 哪些应用可以代替 Word 和 Microsoft Store
  • 怎样保证安全

Linux Mint 是一个免费系统，可以装在太旧、跑不动 Windows 11 的电脑上。它用起来和 Windows 很像，自带免费的上网、邮件和文档应用，至少到 2029 年都会有安全更新。

小提示

  • 菜单（左下角）就像"开始"按钮。
  • LibreOffice已经装好了：能打开和保存 Word、Excel 文件。
  • 软件管理器是免费的应用商店。
  • 先试再换：可以从 U 盘运行，不改动您的电脑。可以在辅导活动上问问。

自己试试：熟悉一下界面

打开 LibreOffice Writer 和软件管理器。

文字版步骤

Linux Mint：菜单（左下角）> 搜索或点击应用。更新：时钟旁边的盾牌图标。应用：菜单 > 软件管理器。

不同版本和更新的菜单名称可能略有不同。

请记住

  • Linux Mint 是免费的。
  • 菜单就像"开始"。
  • LibreOffice 能打开 Word 文件。
  • 用盾牌图标保持更新。
