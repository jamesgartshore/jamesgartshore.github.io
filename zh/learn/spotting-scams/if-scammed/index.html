如果您觉得自己被骗了

本课内容

  • 觉得自己被骗时，马上该做什么
  • 向谁举报，到哪里寻求支持
  • 怎样制作您自己的防诈骗应急卡

如果您觉得自己被骗了，请不要觉得难为情。诈骗是职业罪犯精心设计的，每天都有聪明、谨慎的人上当。最重要的是尽快行动，因为银行越早知道，能做的就越多。

马上该做什么

  1. 给银行打电话。拨打 159 或银行卡背面的号码。说明发生了什么。银行也许能拦截这笔付款或冻结您的账户。
  2. 报案。联系 Report Fraud（以前叫 Action Fraud），网址 reportfraud.police.uk，电话 0300 123 2040。在苏格兰，请拨 101 联系 Police Scotland。如果事情正在发生，比如有快递员正往您家赶，请拨 999。
  3. 修改密码：如果您透露过密码，先从邮箱和银行改起。如果有人进入过您的电脑，在重新使用网上银行前先让人检查一下电脑。
  4. 告诉一个您信得过的人。说出来会好受些，而且对方能帮您留意后续的骗局。

小心"追回钱款"骗局

被骗的人有时会再次被人联系，对方说可以帮您追回钱款，但要收费。这是另一个骗局。Report Fraud 和您的银行绝不会向您收费。

到哪里寻求支持

  • Victim Support：免费、保密的支持热线 08 08 16 89 111，不管您有没有报案都可以打。
  • Citizens Advice 消费者热线：0808 223 1133，针对所购商品或服务的问题。
  • 更多免费帮助请看获取帮助页面。

制作您的防诈骗应急卡

填好并打印出来，放在电话旁边或钱包里。万一出事，就不用在慌乱中到处找号码了。您在这里输入的任何内容都不会被发送或保存。

防诈骗应急卡

停一停。不付款、不点链接、不透露验证码。挂断电话，自己核实。
