消息、照片和语音留言

本课内容

  • 怎样开始聊天并发送消息
  • 怎样发送照片和语音留言
  • 灰色和蓝色对勾是什么意思

WhatsApp 设置好了，该用起来了。不管多长，通过 Wi-Fi 或手机流量发消息都是免费的，还可以发照片和语音留言。

对勾是什么意思

  • One grey tick : your message has been sent.
  • Two grey ticks : it has arrived on the other person's phone.
  • 两个蓝色对勾 : they've read it.

实用小知识

  • 语音留言很适合打字不方便的时候：说话时按住麦克风，说完松手即可发送。
  • 发错了东西？按住那条消息，然后选择删除和为所有人删除。发送后的一段时间内都可以这样做。
  • 要回复某一条特定的消息，把它向右滑动，然后输入您的回复。
  • 别人发给您的照片会保存在您的手机里，所以转发之前请想一想。

自己试试：消息、照片和语音留言

在模拟手机上，和 Sarah 开始一个聊天，然后给她发一条消息、一张照片和一条语音留言。想输入什么都行：不会发送到任何地方。

文字版步骤

  1. 新建聊天：iPhone 上点按右上角的铅笔图标；Android 上点按右下角的绿色按钮。然后点按对方的名字。
  2. 消息：点按底部的输入框，输入文字，然后点按发送箭头。
  3. 照片：点按 +（iPhone）或回形针（Android），选择“照片”或“图库”，点按一张照片，需要的话加上说明文字，然后点按发送。
  4. 语音留言：按住麦克风，说话，然后松手发送。

请记住

  • 点按新建聊天按钮，再点按对方的名字，就能开始聊天。
  • 一个灰色对勾表示已发送，两个灰色对勾表示已送达，两个蓝色对勾表示已读。
  • 按住麦克风录制语音留言，松手即可发送。
  • 按住一条消息可以删除它，可以只为自己删除，也可以为所有人删除。
