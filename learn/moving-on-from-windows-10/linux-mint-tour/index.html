Switching to Linux Mint

In this lesson

  • Where things are in Linux Mint
  • Which apps replace Word and the Microsoft Store
  • How to keep it safe

Linux Mint is a free system you can put on a computer that's too old for Windows 11. It works a lot like Windows, comes with free apps for the web, email and documents, and gets security updates until at least 2029.

Good to know

  • The Menu (bottom left) is like the Start button.
  • LibreOffice is already installed: it opens and saves Word and Excel files.
  • Software Manager is the free app store.
  • Try before you switch : it can run from a USB stick without changing your computer. Ask at a help session.

Try it yourself: find your way around

Open LibreOffice Writer and Software Manager.

The steps, written out

Linux Mint: Menu (bottom left) > search or click an app. Updates: the shield near the clock. Apps: Menu > Software Manager.

Menu names can differ slightly between versions and updates.

Remember

  • Linux Mint is free.
  • The Menu is like Start.
  • LibreOffice opens Word files.
  • Keep it updated with the shield.
