Handy keyboard shortcuts

In this lesson

  • The four most useful shortcuts
  • Which key to use on a Mac
  • How to take a screenshot

A few keyboard shortcuts save a lot of clicking and work in almost every app. On a Mac they use the Cmd key instead of Ctrl.

Good to know

  • Select all : Ctrl + A ( Cmd + A).
  • Copy and paste : Ctrl + C, then Ctrl + V ( Cmd on a Mac).
  • Undo : Ctrl + Z ( Cmd + Z). Brilliant after a mistake.
  • Screenshot : Windows key + Shift + S, Shift + Cmd + 4 on a Mac, or Print Screen on Linux.

Try it yourself: copy your shopping list

Copy a list into an email using the keyboard. Your real keyboard works, or use the buttons.

The steps, written out

Windows and Linux: Hold Ctrl and press A (select all), C (copy), V (paste) or Z (undo).

Mac: Hold Cmd and press A, C, V or Z.

Menu names can differ slightly between versions and updates.

Remember

  • Ctrl (⌘ Cmd on a Mac) + C copies.
  • + V pastes.
  • + Z undoes.
  • + A selects everything.
