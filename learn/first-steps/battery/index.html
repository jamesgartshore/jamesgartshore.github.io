Battery and charging

In this lesson

  • How to make your battery last longer
  • Which apps use the most battery
  • When a battery needs replacing

Battery running out by teatime? A few simple settings help it last longer, and you can see exactly which apps use the most.

Good to know

  • Battery saving mode makes it last longer when it's low.
  • Screen brightness uses the most power: turn it down a little.
  • Charging overnight is fine: modern phones look after the battery.
  • Getting old? Batteries wear out; a replacement can make an older phone feel new.

Try it yourself: make the battery last longer

Turn on battery saving and see which apps use the most.

The steps, written out

iPhone: Settings > Battery > Low Power Mode.

Android (Google Pixel): Settings > Battery > Battery Saver.

Samsung: Settings > Battery > Power saving.

Menu names can differ slightly between phone models and updates.

Remember

  • Battery saving mode helps it last longer.
  • Screen brightness uses the most power.
  • Charging overnight is fine.
  • Old batteries can be replaced.
